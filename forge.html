Forge: AI-Powered 3D Design Platform

Timeline: Sept 2025 | Focus: Generative AI & CAD

Project Overview

"Design at the Speed of Thought." [cite_start]Forge is a browser-based CAD application that lowers the barrier to entry for 3D modeling by allowing users to generate geometry using natural language[cite: 46].

Key Features

    [cite_start]
  • Intent Recognition: Utilized the Google Gemini API to parse user prompts (e.g., "Create a 20mm cube with a 5mm hole") and extract geometric parameters[cite: 45].
    • [cite_start]
  • Custom STL Pipeline: Wrote a custom STL Exporter module that converts the browser-generated geometry into manufacturing-ready files for 3D printing[cite: 45].
    • [cite_start]
  • Responsive UI: Built a chat-centric workflow using HTML5 and Tailwind CSS to create an intuitive user experience[cite: 46].
Tech Stack: Google Gemini API, JavaScript, Tailwind CSS, HTML5.
