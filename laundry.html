Laundry Optimizer App

Location: Morrisville, NC | Focus: Local Logistics Optimization

The Problem

In shared laundry facilities, "machine contention" is a major inefficiency. Residents often find machines full or wait unnecessarily for cycles to finish.

The Solution

I developed a software solution to smooth out demand. The application allows users to:

  • Input their preferred laundry times.
  • View a heat-map of peak usage hours based on historical data.
  • Receive "Green Light" notifications when machines are statistically likely to be free.

Technical Details

The backend utilizes basic optimization logic (linear sorting) to prioritize slots. I am currently working on refining the user interface to make it accessible for non-technical residents in my area.
